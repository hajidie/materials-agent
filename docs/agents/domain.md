# Domain Docs

本仓库采用 single-context：统一使用根目录词汇表和设计决策记录。

## 探索前读取

- 根目录 `GLOSSARY.md`：理解项目已约定的领域术语。
- `docs/adr/`：读取与当前任务相关的 ADR。
- 涉及 Agent、工具或数据边界时，按 `AGENTS.md` 指引读取 `docs/architecture.md` 相关章节。

文件不存在时直接继续，不因缺失而要求提前创建。术语或设计决策实际得到确认后，再由 domain-modeling 等相关技能按需补充。

## 文档布局

- `GLOSSARY.md`：整个项目共用的领域词汇表。
- `docs/adr/*.md`：整个项目的设计决策记录。

## 使用术语

Issue 标题、设计提案、假设和测试名称等涉及领域概念时，使用词汇表中定义的名称，避免使用其中标记为 Avoid 的同义词。

需要的概念尚未收录时，先检查是否误用了项目外的术语；确有缺口时记录为后续 domain-modeling 的输入。

## 处理 ADR 冲突

方案与现有 ADR 冲突时，明确指出冲突的 ADR、差异和重新讨论的理由，不静默覆盖既有决定。
