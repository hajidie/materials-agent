# 保留研究过程内容，不保存逐字播放轨迹

科研聊天需要同时展示模型思考、工具调用前后的行动说明、工具执行状态和可公开的结果摘要，并清楚区分模型生成的解释与实际执行事实。用户在澄清 Q2 的选项含义后确认选择①：当场流式展示，以后展开查看保存的完整过程内容。

保存过程内容，不以永久保存每个字符增量及其到达时间来实现历史回看。完成的步骤、模型思考和工具结果摘要可在历史中查看，失败或中止时已保存的片段标为未完成。相比仅实时展示，这支持后续追溯；相比逐字事件完整重放，这减少了存储和重放协议的负担。

已通过独立过程内容快照、跨分片公开投影和 SSE 快照重连实现，细节见 [架构说明](../architecture.md#研究过程与流式协议)；本决定不引入最终回答 Validator，也不将模型思考视为科研证据。
