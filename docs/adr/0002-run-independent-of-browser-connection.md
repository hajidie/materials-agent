# 任务执行不依赖浏览器连接存活

科研工具可能运行较长时间，刷新、关闭页面或网络断连不应被解释为用户取消任务。用户已确认：页面连接断开后后端继续处理原任务，重新打开页面能够恢复查看；用户明确点击停止才表达停止后续决策的意图，任务自身的完成、失败和预算限制仍然有效。

因此，SSE 订阅负责观察原任务，重连不能创建或重新派发任务。相比连接断开即停止，这要求分别管理执行和订阅的生命周期，但避免浏览器连接状态改变科研任务的执行语义。

用户进一步确认第一版的恢复范围：浏览器断线可以重连查看；后端进程重启后保留记录、明确显示任务中断，由用户触发恢复，且必须先核查已派发工具的原回执，不自动重跑结果不明的操作。

已通过后台任务托管、SSE 累计快照和显式中断恢复实现，细节见 [流式展示设计](../design/streaming-research-process.md)。停止继续沿用现有边界：已派发的 GPU 或 ML 工作可能继续，迟到结果仍保存，不能把停止后续决策描述为撤销已发生的计算。
